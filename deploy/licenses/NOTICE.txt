Third-party components in EmailRelay

The binary embeds the Go runtime and standard library. Go and the Go
subrepositories use the notices in go-LICENSE.txt and go-PATENTS.txt.
The release's Go module versions are recorded in go.mod and go.sum in
the source archive and in Go build information in each executable.

Mail protocol support
  github.com/emersion/go-imap/v2       go-imap-LICENSE.txt
  github.com/emersion/go-message      go-message-LICENSE.txt
  github.com/emersion/go-sasl         go-sasl-LICENSE.txt

Storage and passwords
  github.com/mattn/go-sqlite3          go-sqlite3-LICENSE.txt
  SQLite amalgamation                 https://sqlite.org/copyright.html
  golang.org/x/crypto                 x-crypto-LICENSE.txt, x-crypto-PATENTS.txt

Native Linux archives use musl and GCC runtime support. Their notices are
in musl-COPYRIGHT.txt, libgcc-GPL-3.txt and libgcc-runtime-exception.txt.
GCC runtime library copyright: Free Software Foundation, Inc.

The web interface embeds Nanum Gothic, distributed under the SIL Open
Font License. See NanumGothic-OFL.txt.
